adhammer prebuilt binaries
=========================

Description
------------
The great ["adhammer"](https://github.com/icedracon/adhammer) tool, automatically compiled when there is a new release.

The building workflow is [here](https://github.com/mycodedoesnotcompile2/adhammer_prebuilt_binaries/blob/main/.github/workflows/main.yml).

See the [Github release page](https://github.com/mycodedoesnotcompile2/adhammer_prebuilt_binaries/releases/latest/) of this repository to access prebuilt binaries for different:
- OSes: Linux, Windows, MacOS, Android
- architectures: x86, x64, arm5/7/64, powerpc64le, riscv64gc, mips64el
- libc: GNU, musl
